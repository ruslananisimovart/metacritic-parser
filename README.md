# Metacritic parser

Сервис по расписанию забирает новые игры с Metacritic, пишет резюме отзывов критиков и игроков, находит летсплей на YouTube, расшифровывает его Whisper и делает заключение по словам блогера. Вся работа видна в веб-интерфейсе в реальном времени.

Тестовое задание Skytec, вакансия AI Automation Engineer.

Демо без установки: `https://<аккаунт>.github.io/<репозиторий>/` (интерфейс проигрывает запись настоящей работы сервиса: три прогона, Whisper, летсплеи).

## Что сверх задания

- Нет обложки, трейлера или описания на Metacritic: данные берутся из Steam, затем из Google Play, с проверкой разработчика.
- Модель не перегружается контекстом. Задача разбита на этапы (выбор ролика, заключение, резюме критиков и игроков отдельно), длинная расшифровка режется на части по паузам блогера и разбирается по кускам, пункты потом склеиваются.
- Whisper разбирает длинное видео окнами и отдаёт текст с таймкодами. Ролик без речи блогера отсеивается сразу после расшифровки, до модели, и сервис тут же берёт следующий летсплей.
- Слова модели сверяются с источником: цитата ищется в отзыве или в расшифровке, выдуманное отбрасывается. У пунктов резюме всплывают рецензии, у летсплея таймкоды с переходом в нужный момент ролика.
- Три провайдера модели с переключением из интерфейса: kie.ai, Gemini API, локальная Gemma 4 12B в LM Studio. Модель и Whisper делят видеокарту по очереди и выгружаются после простоя.
- Гибкое расписание, обновление старых игр по сроку, повторный поиск летсплеев, календарь прогонов с фактом и прогнозом.
- Мониторинг: этапы прогона, воркеры, видеокарта, процессор, память, сеть, расход токенов, нерешённые ошибки.
- Каталог с фильтрами по готовности данных, хранилище итераций, выгрузка CSV и ZIP, светлая и тёмная тема.
- Вход в YouTube один раз: у сервиса свой профиль Chrome, cookies обновляются сами.

## Запуск

Нужен Python 3.12. Для летсплеев видеокарта NVIDIA с CUDA 12, без неё `LETSPLAY_ENABLED=false`.

```
pip install -r requirements.txt
cp .env.example .env        # впишите ключ KIE_API_KEY_1 или выберите LLM_PROVIDER=local
```

- Windows: `Metacritic_Parser.bat` (меню: запуск, перезапуск, остановка, вход в YouTube).
- Linux и VPS: `sh metacritic_parser.sh start`, для доступа снаружи `SERVICE_HOST=0.0.0.0 sh metacritic_parser.sh start`.

Интерфейс: http://127.0.0.1:8000/, API: http://127.0.0.1:8000/docs. База, логи и хранилище создаются в папке проекта при первом запуске.

Настройки, API, консольные команды и устройство: [DOCUMENTATION.md](DOCUMENTATION.md).
